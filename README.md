## About

I build practical software that turns messy workflows into clear, usable products. My work spans AI demos, OCR and PDF extraction, deployed React/Next.js interfaces, dashboards, and automation-heavy business tools.

I care about clean UI, readable code, useful documentation, and projects that are easy to understand from the first screen.

## Focus Areas

- AI-assisted tools for translation, computer vision, music generation, and triage prototypes
- Full-stack web apps with TypeScript, React, Next.js, Python, and FastAPI
- OCR, PDF extraction, Excel automation, dashboards, and operational workflows
- Responsive frontend experiences deployed on Vercel
